# 障碍场设计与调参

这篇是给"用方块搭障碍场"用的：**场地怎么搭才飞得动**、**哪一段手感不对该改哪个参数**、
以及**一条命令跑完验收清单**。

## 0. 一条命令验收

```text
node scripts/course-check.mjs --north        # 障碍在场地北侧；东侧用 --east
node scripts/course-check.mjs --north --reach=12
```

它按固定顺序飞五步并打印数字（最近一次在默认参数、净空场地上的实测）：

| 步骤 | 判据 | 实测 |
| --- | --- | --- |
| 1. 悬停稳定性 | 6 s 内水平漂移 ≤ 0.10 m | **0.003 m** ✔ |
| 2. 阶跃响应 | 0.7 m/s 指令下 0.4 m/s 在 1.5 s 内达到 | **1.10 s** ✔（两级滞后，见 §2） |
| 3. 顶速 | 起速后 2 s 内速度在 [0.9, 1.05]×限速 | **1.42 m/s**（限 1.4）✔ |
| 4. 擦碰 | 0.5 m/s 慢速撞上去应"滑过去不坠机" | 需要障碍物 |
| 5. 硬撞 | 全速撞上去应坠机 + `safety_latched` | 需要障碍物 |

**第 4、5 步在没有障碍物时报 `SKIP` 并说明"沿该轴飞了 X m 没碰到东西"**——它不会假装通过。
（这是刻意的：一个不可能失败的清单比没有清单更糟。）

## 1. 场地该怎么搭（用实测数字说话）

| 你的意图 | 依据 | 建议 |
| --- | --- | --- |
| 门/洞做多大能过 | 碰撞盒默认 **0.9 × 0.35 m**（半宽 0.45、半高 0.175） | 1×1 的方块洞很宽松；要做窄门就调小 `collision_half_width_m`/`collision_half_height_m`，代价是**视觉模型比碰撞盒大**（会看起来"穿模"） |
| 到点要停住，通道要留多长 | 顶速 1.4 m/s 时的刹车距离约 **0.56 m**（= 速度 × 两级滞后 0.32 s × 2）；实测 0.5 m/s 滑行 0.266 m | 终点前留 ≥ 0.8 m 余量；点到点精度实测 **0.38 cm**（3 m 腿） |
| 积分精度会不会把门算歪 | 子步积分后每加速段的矩形偏差 **0.875 cm** | 1 m 的门有约 50 cm 余量，够用 |
| 转角/绕柱要多快 | 速度响应 0.20 s 且**过阻尼**（不冲过指令），姿态环 0.12 s | 绕柱以 ≤ 0.8 m/s 过；想让转弯更"脆"就调小 `attitude_time_constant_s`（0.12 → 0.08） |
| 想要"撞门框不毁、继续飞" | 坠机阈值：水平 0.8 m/s、垂直 1.5 m/s；擦碰按 `restitution` 反弹、沿面按 `friction×g` 减速 | 把 `crash_horizontal_mps` 提到 1.3–1.4，门框就能随便蹭；`restitution` 0.25 → 0.5 会更弹 |
| 场地抬高/下沉 | NED 原点 = 场地中心（`field status` 打印世界坐标） | 用 `/minidrone field` 定义场地，别让飞机和场地各说各话 |
| 想飞得更快 | 限速是**合同**上限，且与健康信标周期耦合：`周期 × 限速 < 0.10 m` | 提高 `max_horizontal_speed_mps` 必须同时缩短 `MavlinkTransport.MOCAP_HEALTH_PERIOD_MS`（单测会提醒你），见 `docs/vehicle-model.md` §2 |

## 2. 症状 → 参数

| 症状 | 先改这个 | 说明 |
| --- | --- | --- |
| 太"飘"、松开还要滑很远 | `attitude_time_constant_s` ↓、`drag_coefficient` ↑ | 姿态回正慢 + 阻力小 = 滑得远 |
| 太"木"、给指令半天不动 | `motor_time_constant_s` ↓、`max_tilt_deg` ↑、`thrust_to_weight` ↑ | 推力矢量要靠倾角，倾角小就加速慢 |
| 爬升/悬停"顶不动"、低空掉高 | `thrust_to_weight` ↑ | 2.2 = 悬停油门 45%；接近 1.0 就没余量 |
| 顶速不够 | `max_horizontal_speed_mps` ↑（**同时缩信标周期**）+ `drag_coefficient` ↓ 或 `max_tilt_deg` ↑ | 物理顶速 = `sqrt(m·g·tan(倾角)/阻力)`，默认 1.86 m/s |
| 擦一下就坠机 | `crash_horizontal_mps` ↑ | 默认 0.8 m/s，全速 1.4 撞上去必毁 |
| 撞上去"黏"在墙上 | `restitution` ↑、`friction` ↓ | 0.25/0.6 是默认；要"弹开"就 0.5/0.3 |
| 过门老蹭 | `collision_half_width_m` ↓ | 碰撞盒与视觉解耦的代价见 §1 |
| 转弯/起步太猛 | `attitude_time_constant_s` ↑、`max_tilt_deg` ↓ | 更快=更猛，反之更稳 |

**改法**：游戏里 `/minidrone physics set <名字> <数值>`（立刻生效，不用重启）、`/minidrone physics` 看全套含推导量、
`/minidrone physics reset` 回默认；或用启动参数 `-Dmini_drone.vehicle.<名字>=<数值>`
（**必须放在 JVM 参数位**，放到启动参数末尾会被当成游戏参数丢掉——这一条实测过）。

## 3. 已知的边界（别指望它做这个）

- **触地不弹跳**：落地相位在接触瞬间完成、飞机停稳（残余上弹速度不积分）。这是刻意的：降落该落下来。
- **没有风、没有电机单个失效、没有桨叶拍动**：`docs/dynamics-roadmap.md` 里列了要走到 SITL 级还缺什么。
- **转弯时的高度**由垂直通道主动保持（不会因为倾斜而掉高），这是控制器行为，不是气动缺失。
- **姿态是速率环 + 倾斜-加速度耦合**，没有完整 6DOF 力矩/惯量：猛撞时的翻转姿态不会出现。
